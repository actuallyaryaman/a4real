Integrity Box + TrickyStore + HMA-OSS Setup Guide

Installing and configuring Integrity Box, TrickyStore, and HMA-OSS on rooted Android.

By Aryaman Srivastava

In this article

1. Download the following modules2. Initial Installation3. Configure TrickyStore (via WebUI)4. Run Integrity Box Action Button5. Configure HMA-OSS

Follow the steps in order. Do not skip reboots where mentioned.

1. Download the following modules

  • Zygisk-Next
    • TrickyStore
  • Tricky Addon
  • Integrity Box
  • Lsposed-Irene
  • HMA-OSS
  • HMA-config

⚠️ Do not install PIF

2. Initial Installation

Install these modules in order, reboot as mentioned:

  1. Zygisk Next.
    • Reboot (Set zygisk deny list policy as unmount only and enable the two check boxes)
  2. TrickyStore
  3. Tricky-Addon-Update-Target-List
    • Reboot
  4. Lsposed-Irene
    • Reboot
  5. Integrity Box
    • Reboot

3. Configure TrickyStore (via WebUI)

  1. Select ALL → Deselect unnecessary apps
  2. Keybox → Valid
  3. Security patch → Auto
  4. SAVE

4. Run Integrity Box Action Button

Check your integrity status. Voila!

5. Configure HMA-OSS

  1. Open HMA-OSS
  2. Restore the downloaded config
  3. Open Manage Apps → Configure your Banking Apps
    • In template config: Select All presets options, Select All templates, Select all settings template, Select All settings preset.

Everything should work as intended.
