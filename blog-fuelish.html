Fuelish

A Simple Way to Track Fuel Prices

By Aryaman Srivastava

Keeping track of daily fuel price changes can be frustrating — different websites, slow updates, and no quick way to compare. That’s why I built Fuelish, a simple web app that lets you instantly check the latest petrol and diesel prices across different states in India.

With just a few clicks, you can:

  • View real‑time fuel prices for your state and district
  • See daily changes in petrol and diesel rates
  • (Soon) find the cheapest pump within a 50‑km radius

No sign‑ups, no ads — just clean, useful information.

Built using HTML, CSS, JavaScript, and Leaflet (OpenStreetMap), Fuelish runs entirely in your browser and is hosted on GitHub Pages. Light, fast, and open‑source — everything a modern web tool should be.
