Arch Setup Script

A menu-driven Bash utility for fast, repeatable system management.

By Aryaman Srivastava

In this article

✨ Features

A lightweight, menu-driven Bash script to automate system setup and maintenance on Arch Linux.
From updating packages and installing yay to configuring your shell, managing package lists, and setting battery limits — everything is just a few keystrokes away.

✨ Features

  • Update system and install essential packages
  • Manage and restore package lists
  • Configure Git and shell preferences
  • Enable parallel downloads for faster updates
  • Organize your Downloads folder automatically

⚠️ For Arch Linux only — review all commands before execution.
