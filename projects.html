Agentic threat huntingNTU · SE6014 · Team project

TRACE

From an unfamiliar log source to an investigation you can inspect.

View recorded demo ↗Project repository ↗

TRACE brings log onboarding, agent-assisted investigation, and independent evidence checks into one team project.

My work covers unknown-schema generation, validation and reuse, shared source onboarding, and the UI/UX. The interface follows a recorded SSH case through six stages, with source records, query receipts, and claim checks available to inspect.

The demo uses synthetic evidence. It supports analyst review; a verified citation is not a guarantee that an agent’s conclusion is correct.

Zero-knowledge proofsNTU · SE6003 · Academic project

The Hidden Colouring

How do you prove you know an answer without giving it away?

Try the lesson ↗Project repository ↗

An interactive guide to zero-knowledge proofs, built around a graph-colouring puzzle. Seal a colouring, challenge one edge, then open just the two answers needed to check it.

The Python protocol backs the lesson with SHA-256 commitments, public-transcript verification and tamper checks. The Protocol Lab lets visitors inspect messages and test altered openings.

This is an educational implementation with explicit assumptions, not production cryptography. Tests and empirical results do not prove zero knowledge.

Python · SHA-256 commitments · Graph three-colourability

Android privacyv0.1

Skopos

An Android module for choosing which contacts each app gets to see.

See Skopos ↗

All contacts, a few selected contacts, or none. Skopos applies those choices through Vector/libxposed; apps you haven’t configured keep their normal behaviour.

Built for Android 16 and a rooted Vector/libxposed setup. No runtime network dependency or telemetry.

Kotlin · Android 16 · Vector / libxposed
